# SnapFeed

A full-stack social media application where users can register, authenticate, upload media, and view posts.

**Live Demo:** [SnapFeed](https://snapfeed-seven.vercel.app/login)  
**Backend API Documentation:** [FastAPI Swagger UI](https://snapfeed-45ur.onrender.com/docs)

## Overview

SnapFeed is a personal project built to develop my full-stack engineering skills, with a primary focus on backend development. It provides hands-on experience with REST API design, authentication, relational databases, media uploads, and application deployment.

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT-based authentication

### Frontend
- React
- Vite
- CSS

### Infrastructure and Services
- **Neon:** Hosted PostgreSQL database
- **Cloudinary:** Cloud-based media storage
- **Render:** Backend hosting
- **Vercel:** Frontend hosting

## Features

- User registration and login
- JWT-based authentication
- Protected API endpoints
- Media uploads and post captions
- User-specific post retrieval
- Profile and uploads views
- Cloud-based media storage
- Deployed frontend and backend

## My Focus and Contributions

My primary focus in this project is **backend development**. I have been working on API design, request handling, authentication, database integration, protected endpoints, and deployment.

I have also worked on integrating the frontend with the backend API and troubleshooting issues across local and production environments.

For parts of the frontend UI styling and CSS, I used AI assistance to generate and refine implementations. I review and adapt this output as part of my development workflow while continuing to strengthen my frontend skills.

My goal is to understand the implementation decisions behind the code, improve my debugging skills, and become more independent in building and maintaining applications.
